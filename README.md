# workflow

# RUNNING THE FRONTEND/REACT:
# 1. Install Node Package Manager (NPM), or Node Version Manager (NVM) which will take care of installing NPM for you.
#   Instructions for installing NVM: https://github.com/nvm-sh/nvm?tab=readme-ov-file#installing-and-updating

# 2. Once you have NPM, via your terminal/command-line, navigate to the workflow_REACT folder.

# 3. In the workflow_REACT directory, run these commands to install the necessary dependencies:
#   "npm install"
#   "npm install react-router-dom"

#   Then finally to run the application: 
#   "npm run dev"

# 4. After running the previous commands, the application will start up. A message will 
#    appear stating what port the application is running on. You should be able to click the link, or navigate to the app in your browser:
#   "http://localhost:PORT_NUMBER"

# 5. When finished, you can enter "q" into the terminal/command-line to close the application.


# RUNNING THE BACKEND/SPRINGBOOT:
# 1. Install Java/JDK

# 2. In the IDE, if prompted, load the Maven dependencies for the project and/or select the SDK (Java 17 should suffice).

# 3. Navigate to the main method and hit the play button to run the application:
#       workflow > workflowJavaSpringBoot > src > java > com.workflow > WorkFlowApplication
